# Shared implementation and source packages

Use [d12_training](d12_training/) for the integrated D12 modules, configs, launchers, and setup notes used by the analyses in this repository. The matching upstream NanoChat source, training environment, model packs, tokenizer assets, and data are separate requirements for a full training rerun.

`source_packages/` contains archived experiment-support packages retained for reference. Some packages contain overlapping historical versions; the integrated `d12_training/` tree is the recommended starting point for the current analyses.

Navigate from the [paper-section map](../../README.md) for section-specific entrypoints.
