# Expanded base package: reference only

This is the source tree inside `runpod_d22_causal_speedrun_v2.tar.gz`, expanded for browsing.
It is an **older base**, not the final Table 2 protocol. Its original defaults include
alpha 0.60 and exploratory, outcome-gated run logic. The final alpha-0.70 supervisor
patches this base, fixes the three seeds, and runs every treatment seed.

Python bytecode/cache files were omitted from this expanded copy. Original checksum
files have been retained for reference and can refer to omitted bytecode. Do not
interpret their absence as a change in the canonical archive: the byte-identical
archive is retained in each archived supervisor bundle that requires it.
See `../README.md` before using any launcher. The repository CPU-analysis workflow
does not invoke these training or cloud-provisioning launchers.
