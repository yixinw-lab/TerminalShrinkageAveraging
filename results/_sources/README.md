# Saved analysis inputs

The folders here contain numerical records, summaries, manifests, and compact run metadata used by the CPU analysis scripts. Paper-facing tables and figure data are written to the section-specific folders under `results/`.

- `d12_replicated` contains the development and confirmation records used by the main replicated D12 analyses.
- `d12_window_estimators` contains the five-stream checkpoint-window and alternative-estimator records.
- `d12_preliminary` contains the single-trajectory preliminary sweeps used in Appendix B.8.
- `app_b_6_parameter_roles/run_archive` contains the development and confirmation records plus the frozen rule for Appendix B.6.
- `app_b_7_groupwise_floor/run_archive` contains the protocol and run records for Appendix B.7.
- `d22_runs` contains the saved depth-22 run summaries used by the Section 4.5 analysis.

Machine-specific paths in saved metadata have been replaced by environment-style placeholders; numerical measurements and experimental identifiers are unchanged.
